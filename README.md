# 🌾 Agricultural Crop Yield Analysis Dashboard

## 📊 Project Overview

This project analyzes agricultural crop data using Microsoft Excel.
The dashboard provides interactive insights into crop production,
yield, cultivated area, rainfall, irrigation methods, soil types,
fertilizer usage, states, districts, and yearly production trends.

## 🎯 Project Objectives

- Analyze crop production across different states and districts.
- Compare average yield among different crop types.
- Analyze production across different seasons.
- Study the relationship between irrigation type and crop yield.
- Analyze soil type and fertilizer usage.
- Identify top-performing districts.
- Analyze yearly crop production trends.
- Create an interactive Excel dashboard.

## 📈 Dashboard Analysis

### State-wise Crop Production
Analyzes total crop production across different states.

### Average Yield by Crop Type
Compares the average yield of different crops.

### Season-wise Production
Analyzes crop production across Kharif, Rabi, and Zaid seasons.

### Irrigation Analysis
Compares average crop yield across different irrigation types.

### Soil Type Analysis
Analyzes average yield based on different soil types.

### Fertilizer Analysis
Compares crop production across different fertilizer types.

### Top 10 Districts
Identifies the top-performing districts based on average yield.

### Year-wise Production Trend
Analyzes crop production trends across different years.
